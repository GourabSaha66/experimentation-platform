# Experiment Lab

Power calculator, A/B test analysis (t-test, chi-square, multiple-testing correction, sequential testing, Bayesian) and
observational causal methods (propensity matching, difference-in-differences, synthetic control) with plain-English conclusions.

Source code and documentation: see the GitHub repository linked from the project README.
